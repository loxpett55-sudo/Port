# StarFluff — живые обои рабочего стола

Electron-приложение с анимированным «живым» фоном: пушистый персонаж в
фиолетово-голубой палитре на звёздном небе. Персонаж дышит и покачивается,
волосы и серебряная ветка колышутся с порывами ветра, глаза периодически
открываются, моргают и следят за курсором мыши, поверх плывут мерцающие
звёзды-искры.

## Структура проекта

```
desktop-character/
├── main.js               # главный процесс: окно-обои, трей, автозапуск,
│                         #   глобальный опрос курсора (30 Гц)
├── preload.js            # contextBridge: безопасный мост IPC → renderer
├── renderer/
│   ├── index.html        # слои сцены
│   ├── style.css         # позиции слоёв, маска волос, переходы
│   └── script.js         # rAF-цикл: покачивание, ветер, моргание, взгляд, искры
├── assets/
│   ├── base-closed.jpg   # базовый слой — персонаж с закрытыми глазами
│   ├── eye-left.png      # патч левого открытого глаза (альфа-растушёвка)
│   ├── eye-right.png     # патч правого открытого глаза
│   ├── eyes.json         # координаты патчей в сцене 1024×1024
│   └── tray.png          # иконка трея
├── build/icon.png        # иконка приложения (для electron-builder)
└── tools/prepare_assets.py  # генерация ассетов из двух исходных изображений
```

## Как устроены слои

Исходники — два цельных кадра (глаза закрыты / глаза открыты), поэтому слои
подготавливаются программно (`tools/prepare_assets.py`):

- **База** — кадр с закрытыми глазами, растянут на экран (cover) с небольшим
  запасом масштаба, чтобы покачивание не оголяло края.
- **Волосы/декор** — копия того же кадра, обрезанная CSS-маской
  (градиент к прозрачности у линии глаз). Слой качается независимо от базы
  вокруг оси у «подбородка»; плавное затухание маски прячет шов.
- **Глаза** — патчи открытых глаз, вырезанные из второго кадра по областям
  реальных отличий (найдены попиксельным diff'ом) с запасом 30 px и мягкой
  альфа-растушёвкой 22 px. Патчи бесшовно ложатся на базу и могут сдвигаться
  на ±4 px для эффекта взгляда.
- **Искры** — процедурный canvas поверх всего: 70 мерцающих частиц в
  сине-фиолетовой палитре, при порыве ветра разлетаются быстрее.

## Анимации

| Эффект | Реализация |
| --- | --- |
| Покачивание | rAF-цикл: `rotate` ±0.45°, вертикальный «bob» ±4 px, «дыхание» масштабом ±0.4 %, периоды 5.5–7 с |
| Ветер | случайный порыв каждые 5–8 с на ~1.3 с; амплитуда и скорость слоя волос плавно (экспоненциальный лерп) вырастают в ~3 раза и возвращаются |
| Моргание | каждые 4–7 с глаза открываются на 150 мс; с вероятностью 25 % — «пробуждение» на 1.8–4 с |
| Взгляд | глобальная позиция курсора (`screen.getCursorScreenPoint()`, 30 Гц) → IPC → сдвиг патчей глаз до ±4 px с лерп-сглаживанием |

Все переходы сглажены: экспоненциальный лерп, независимый от частоты кадров,
плюс CSS-transition на прозрачности глаз — резких скачков нет.

## Запуск в разработке

```bash
cd desktop-character
npm install
npm start
```

## Сборка инсталлятора (Windows, NSIS)

```bash
npm run dist
```

Итог — `dist/StarFluff Live Wallpaper Setup 1.0.0.exe`:
устанавливает приложение в `Program Files` (perMachine), создаёт ярлыки на
рабочем столе и в меню «Пуск», запускает приложение после установки
(`runAfterFinish: true`).

## Автозапуск

- При первом запуске упакованного приложения `app.setLoginItemSettings({ openAtLogin: true })`
  добавляет запись в `HKCU\Software\Microsoft\Windows\CurrentVersion\Run`.
- В иконке трея есть чекбокс «Автозапуск при входе в систему» и пункт «Выход».
- В dev-режиме (`npm start`) автозапуск не регистрируется.

## Поведение окна

Окно fullscreen, без рамки, `skipTaskbar: true`, `focusable: false` — оно не
перехватывает фокус активных приложений и ведёт себя как обои. На Linux
дополнительно ставится `type: 'desktop'` (слой рабочего стола).

### Интеграция как истинные обои Windows (опционально)

Сейчас окно — обычное fullscreen-окно (иконки рабочего стола под ним
недоступны). Чтобы анимация оказалась **под** иконками рабочего стола,
нужен трюк с `WorkerW`: послать `0x052C` окну `Progman`, найти созданный
`WorkerW` и переподчинить ему окно приложения через `SetParent`. Это требует
нативного модуля (например, `electron-as-wallpaper` или собственная
обёртка над WinAPI через `koffi`/`node-ffi-napi`) и добавляется отдельным
слоем в `main.js` после `createWindow()` — специально вынесено за рамки
базовой версии, чтобы не тянуть нативные зависимости.

## Перегенерация ассетов

Если появятся новые исходные кадры:

```bash
pip install Pillow
python3 tools/prepare_assets.py --closed путь/к/закрытым-глазам.jpg --open путь/к/открытым-глазам.png
```

Скрипт сам найдёт нужные области, вырежет патчи и обновит `assets/eyes.json`
(координаты также захардкожены в `renderer/style.css` — сверить при смене кадров).
